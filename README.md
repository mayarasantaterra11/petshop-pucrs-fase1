# Patinhas & Cia — Fundamentos de Sistemas Web (PUCRS)

Projeto acadêmico de Mayara Sampaio de Campos Santaterra.

## Conteúdo
- `index.html`: início, cabeçalho e menu de navegação.
- `produtos.html`: três categorias, com dois produtos cada; imagens ilustrativas locais, descrição e preços.
- `servicos.html`: serviços, descrições, valores e informação de tele-busca.
- `sobre.html`: contato demonstrativo e autoria.
- `imagens/`: ilustrações SVG locais (substituir por fotos reais, se exigido).

## Tecnologias
Somente HTML5, sem CSS, Bootstrap ou JavaScript.

## Publicação no GitHub Pages
1. Faça login no github.com e crie um repositório público chamado `petshop-pucrs-fase1`.
2. Envie os arquivos e a pasta `imagens` para a raiz do repositório (não envie o ZIP como único arquivo).
3. Abra Settings > Pages, selecione Deploy from a branch, branch `main`, pasta `/(root)`, e salve.
4. Copie o endereço do repositório e o endereço do GitHub Pages para o PDF de entrega.

Observação: a conta e a publicação precisam ser realizadas pelo aluno. Os contatos e valores são fictícios.
